# 문제 분석

로또 숫자 [1,45]
로또는 중복되지 않는 [1,45] 중 6개 선택

로또 말고 `당첨 번호`는 [1,45] 중 7개인데, 그 중 하나는 보너스 번호임
당첨은 1등부터 5등까지 있고,

기준은 일반 당첨 번호가 몇 개 일치하느냐
특히 5개가 일치했을 때만 보너스 번호를 체크한다
이건 로또 객체한테 당첨 번호 전달해주고,
각각의 일치 개수와 보너스 일치 여부를 반환하는 느낌으로
그리고 그거 활용해서 등수 판별하는 느낌

구입 금액을 입력하면 그만큼 로또를 산다
1개당 천원

최종 등수 발표할 때는 사용자가 직접 번호를 입력한다
당첨번호 6개 보너스 1개

당첨 통계를 출력하고 종료

잘못된 값을 입력하면 `IllegalArgumentException`
"ERROR로 시작하는 에러 메시지 출력 후 재입력"

일단 현재 시점에서 식별가능한 건
로또, 당첨 번호, 당첨 번호와 비교한 결과, 일치조건과 상금
수익률 계산할 때에는 long 써야할듯?

구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.

보너스 번호를 입력 받는다.
